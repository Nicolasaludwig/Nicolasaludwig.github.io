# Nicolasaludwig.github.io

-- Nicolas Arqueros Ludwig — Portfólio Pessoal

"Ideias que ganham forma" — Portfólio digital interativo inspirado na estética futurista, partículas de estrelas dinâmicas e animações imersivas em 3D.

-- Sobre o Projeto

Este projeto consiste na criação de um site de portfólio pessoal com belo visual, desenvolvido com tecnologias web modernas (HTML5, CSS3 e JavaScript puro). O layout apresenta uma moldura estilo navegador retro-futurista, tons profundos de azul monocromático, efeitos translúcidos e interatividade fluida.

-- Principais Características

Design Glassmorphism: Elementos translúcidos com desFOQUE (backdrop-filter) e bordas brilhantes.

Animações em JavaScript:

Geração dinâmica de estrelas cintilantes de fundo.

Efeito de inclinação 3D (Tilt Effect) interativo na foto e nos cards ao mover o cursor.

Efeito visual de Ripple (ondas de brilho) ao clicar nos botões.

Totalmente Responsivo: Adaptado perfeitamente para desktops, tablets e smartphones.
